# Changelog

## 1.1.0

Promotes the qualified rc4 pipeline on the tested Windows laptop. Records clean extraction, single-job unattended crash recovery, the complete native export cycle at 100% scaling, and supervised sleep and shutdown. Retains 1.0.3 for rollback. Ambiguous multi-job recovery still requires manual review.

## 1.1.0-rc3 public source

Introduces VlogSync branding, supervised restart and retry controls, filesystem-only publication, content checks and guarded power actions. The first public history contains a sanitized source baseline.

Adds exact-title crop recognition, more robust export settings and bitrate readback, and a supervised 100% display qualification fixture.

## 1.1.0-rc4

Standalone camera and setup helpers remove Process Vlogs imports. The archive requires separately installed FFmpeg and CapCut. Adds a single fail-closed native crash retry and stronger window and completion recognition.

## 1.2.0-rc1

Added Import and Export tabs, review and activity views, folder access, settings, clearance and diagnostics. The adapter reuses the controller CLI and its journal. Reservation and execution accept a reviewed preview checksum. Simulated qualification is separate from the live workspace.
