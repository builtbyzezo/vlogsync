# Roadmap

## Phase 1

Version 1.1.0 completes Phase 1 on the qualified Windows laptop. Preserve the standalone camera adapter, previous rollback, and production safety guards. A second Windows computer requires device and installation preflight before use. Ambiguous multi-job recovery remains a manual review.

## Phase 2

Version 1.2.0 provides a local operator panel with explicit controller actions. Connecting a device can open the panel and will require operator approval to start exports. Editor and publishing workflows are separate.

## Phase 2 qualification

The qualified laptop completed a disposable native panel cycle with filesystem verification and preset restoration. Continue documenting any device-specific limitations before activating other computers. CapCut Space, edited video export and publishing remain planned.

## Phase 3

Version 1.3.0 qualifies local editor handoff, operator-controlled native Space transfers, verified master substitution and reviewed final batch export on the supported laptop. Publishing automation and second-computer qualification remain separate.
